# 系列圣经（Series Bible）模板

> `series/bible.md` 是整季**唯一真相**：每集只引用、不重问。同时落主会话画布文本节点（group `series bible`）。
> 参数以本片型默认值（90s / 9:16 / 中文 / 无字幕 / balanced）为基线，用户改口时改这里并显式确认影响面。

---

## 1. 规格（写死，全季不变）

| 项 | 值 | 变更影响 |
|---|---|---|
| 画幅 | `9:16` | 改 = 全部卡片与片段作废 |
| 单集时长 | `90s`（17–18 镜，124 帧 ≈ 5.17s） | 改 = 镜头表与片段重做 |
| 集数 | `{N}` | 改 = 分集目录重排 |
| 语言 | 中文 | 改 = 台词全部重写 |
| 画面内字幕 | `none` | 改 = 逐镜 prompt 重写 + 重渲 |
| 视频档位 | `balanced` | 改 = 整季重渲（链内首遍尺寸必须一致） |
| 图片档位 | `quality` | 改 = 卡片重出 |
| 角色卡引用 | `single` | 改 = 已产集重渲 |
| 审查节奏 | `batch` | 只改人工确认时机 |
| 交付画质 | 原生 768×1344（样片后可改逐镜超分 1080） | 改 = 逐镜超分 + 重新拼接 |
| 视觉风格 | `cinematic-live-action` | 改 = 全部资产与片段作废 |

---

## 2. 故事骨架

- 一句话故事 / 核心冲突 / What-if
- 三幕结构：建置（第 X–Y 集）· 对抗（第 Y–Z 集）· 高潮与结局（第 Z–末集）
- 全剧节奏波形（文字）：高潮点、低谷点、付费卡点位置
- 爽点矩阵：按集分布（打脸 / 反转 / 揭露 / 情绪 / 危机），同类不连续超过 3 集
- 反派体系：小反派（1–3 集解决）→ 中反派（三轮交锋）→ 大反派（分层揭示）→ 隐藏反派（≥3 处伏笔）
- 感情线弧线：关键节点 + 集数标注
- 结局设计与伏笔回收清单

---

## 3. 付费卡点与钩子

| 集号 | 位置百分比 | 类型 | 悬念设计 | 下一集回应（前 30s） |
|---|---|---|---|---|
| EP{10} | 12% | 💰 身份即将曝光 | … | … |

- 卡点分布：8–12% / 18–25% / 35–45% / 末 3–5 集
- 每集钩子类型（悬念/反转/情绪/信息/危机），同类不连续超 3 集
- **一个结尾只放一个主钩子**

## 4. 人物（视觉锚点 + 状态卡需求）

| 角色 | 定位 | 视觉锚点（脸/发型/身材/服饰主色/签名道具/不可改特征） | 状态卡（持续 ≥3 镜或跨 ≥2 集才建） | 集范围 |
|---|---|---|---|---|
| 林晚 | 女主 | … | 常服-白衬衫 / 受伤-擦伤 / 晚宴-黑裙 | 1–80 |

> 只持续 1–2 镜的变化**不建卡**，写进镜头 prompt。

## 5. 场景与道具

| 场景 | 内外/日夜 | 连续性地标（名称：屏幕位置） | 光位基线 | 复用集 |
|---|---|---|---|---|
| 总裁办公室 | 内/日 | door-frame:右1/3 · desk:桌中 · drawer:右下 | 顶光主 + 右侧冷反光 | 1–60 |

| 道具 | 叙事功能 | 状态变化 | 复用集 |
|---|---|---|---|
| 离婚协议 | 权力反转的物证 | 平整 → 滑落桌沿 | 3–12 |

## 6. 资产台账（跨集复用的唯一来源，与 `production-state.json` 同步）

| 类型 | 名称/状态 | 资产 id | 版本 | 适用集 | 入库 |
|---|---|---|---|---|---|
| 角色 | 林晚·常服 | `character:…` | v1 | 1–20 | ✓ |
| 角色 | 林晚·常服（三视图） | `character:…` | v1 | 备选 | ✓ |
| 场景 | 总裁办公室 | `scene:…` | v1 | 1–60 | ✓ |
| 道具 | 离婚协议 | `scene:prop-divorce-paper` | v1 | 3–12 | ✓ |

> 入库由用户在画布点「入库」；AI 只记录 id。资产改名不影响 id。

---

## 7. 合规基线

- series-writer 的 compliance 清单要点（红线 / 高风险 / 正向价值观）
- 画面侧补：暴力、血腥、擦边、真实品牌标识、真实人物肖像
- 每集 ① 的「合规标记」为空也必须写 `无`

## 8. 剧本流水线状态

- 每批 5–10 集；剧本领先影像 5–10 集
- 已完成：`EP001–EP0NN` ｜ 下一批：`EP0NN–EP0MM`
