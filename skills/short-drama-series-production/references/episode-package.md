# 集制作包（Episode Package）规范与模板

> 本文件是 `short-drama-series-production` 的**唯一交接物格式**。系列层（剧本/圣经）→ 生产层（story-short-generator STEP 3–8）之间只传这一个包。
> 原则：**系列层给「拍什么」，生产层定「怎么拍」。** 包里不写每秒指令、不写参考锚点坐标、不写口型——那些是生产层的实测资产。

---

## 1. 六节结构（顺序固定）

```markdown
# EP{NNN} 集制作包

## ① 集元数据
## ② 场次表
## ③ 对白表
## ④ 8 列镜头意图
## ⑤ 本集资产清单
## ⑥ 生产参数预填
```

落两个地方、内容必须逐字一致：
1. 文件 `series/episodes/epNNN/package.md`（归档 / 续跑）
2. 该集画布文本节点，`group="story planning"`，标题 `EP03 集制作包`（生产用）

---

## 2. 8 列镜头意图（系列的输出、生产的输入）

| # | 列 | 内容规则 | 例 |
|---|---|---|---|
| 1 | 镜号 & 时长 | `S01 / 5.2s`；优先 124 帧（5.17s），短镜 107（4.46s）/ 90（3.75s）；≤15s | `S03 / 5.2s` |
| 2 | 场 | 关联 ② 场次号 | `SC01` |
| 3 | 说话人 & 台词 | **逐字**；一镜一个说话人；`silent` 镜写 `—` | `林晚：你确定要这么做？` |
| 4 | 表演意图 | 情绪 + 身体动作 + 眼神；不写秒级拆解 | `压着火，指尖点着协议推到桌心` |
| 5 | 景别 & 运镜 | 特写/近景/中景/全景 + 推拉摇移/锁定/环绕；**相邻镜不要重复景别** | `近景 / 缓推` |
| 6 | 空间位置 | 人物与地标在画面里的相对位置（引用 ⑤ 的地标名） | `林晚：左前景；协议：桌中；门框：右1/3` |
| 7 | 续接意图 | `起链` / `接 S0x`（**建议值**，最终由生产层按场景边界定）；跨场景边界写 `转场` | `接 S02` |
| 8 | 集内节拍 | `钩子` / `爽点-打脸` / `反转` / `揭露` / `情绪点` / `危机` / `💰卡点` | `爽点-打脸` |

**8 列 → 生产层七列的映射**（生产层负责形式化，不要在这里预写七列）：

| 七列 | 来源 |
|---|---|
| 镜头编号 & 时长 | 列 1 |
| 连续性衔接 | 由列 4/6 与上一镜推导（生产层写） |
| 续接 | 列 7 的建议值 → 生产层按实际场景边界重定 |
| 参考锚点（空间+身份） | 列 6 + ⑤ 的资产 id/地标（生产层补光位/退场状态） |
| Hook 类型 | 列 8 按映射表转换（见 §5） |
| 镜头描述（每秒指令） | 列 4/5 由生产层展开为逐秒指令 |
| 音频与对白轨 | 列 3 + 列 4（生产层补口型/音效/字幕） |

## 3. 镜头预算（先算再排，不许倒过来）

```
镜长(s) ≈ 台词字数 ÷ 4 字/秒 + 0.5–1s 反应/动作尾
90s 集 ≈ 17–18 镜（124 帧 ≈ 5.17s）
对白镜数 = 镜头预算 − 动作/反应/特写镜(3–4) − 转场镜(0–1)
对白句数 ≤ 对白镜数（一镜一说话人）
整集台词总字数 ÷ 4 字/秒 ≤ 90s（超了砍台词，不压语速）
```

**场次压缩**：上游剧本的「3–5 场」按**物理场景**合并——同一间办公室里的多次换景算 1 场；只有换物理地点才需要转场镜（每个边界 1 镜，占预算）。90s 集建议 **1–2 个物理场景**。

---

## 4. 完整示例（90s · 18 镜 · 2 场景 · 14 句对白 + 3 动作 + 1 转场）

```markdown
# EP003 集制作包

## ① 集元数据
- 集号/标题：EP003《离婚协议》
- 目标时长：90s ｜ 镜数预算：18
- 付费卡点：否 ｜ 集内主干节拍：爽点-打脸 → 反转 → 钩子
- 前情（EP002 结尾）：顾言当众否认婚约；林晚被赶出股东大会
- 下集预告：林晚拿出股权代持协议，顾言第一次失控
- 合规标记：无（无暴力/擦边；金钱冲突用合同与股权表达）

## ② 场次表
| 场 | 内外/地点/日夜 | 出场 | 事件 | 冲突升级 |
|---|---|---|---|---|
| SC01 | 内 · 总裁办公室 · 日 | 林晚、顾言 | 林晚递上离婚协议，顾言羞辱她"净身出户" | 从冷嘲到当众扔协议 |
| SC02 | 内 · 办公室外走廊 · 日 | 林晚、助理 | 助理追上递回一份文件，林晚看到"股权代持" | 反转揭示：她才是控股方 |

## ③ 对白表
| # | 说话人 | 台词（逐字） | 情绪 | 目标时长 | 字幕 |
|---|---|---|---|---|---|
| 1 | 顾言 | 签了它，你一分钱都别想从这个家带走。 | 居高临下 | 3.5s | none |
| 2 | 林晚 | 我只要我该得的那一份，不多不少。 | 平静 | 3.0s | none |
| 3 | 顾言 | 你该得的？这三年你吃穿用度，哪一样不是我给的？ | 讥讽 | 4.5s | none |
| 4 | 林晚 | 顾总，账我会自己算清楚，不用你提醒。 | 冷笑 | 3.0s | none |
| 5 | 顾言 | 算？你拿什么跟我算这笔账。 | 逼近 | 3.0s | none |
| 6 | 林晚 | 拿你不敢让董事会看见的那份东西。 | 抬眼 | 4.0s | none |
| 7 | 顾言 | 你威胁我？你也配站在这里跟我说话。 | 拍桌 | 3.5s | none |
| 8 | 林晚 | 配不配，三年前就已经定下了。 | 转身 | 4.0s | none |
| 9 | 顾言 | 站住！把地上的协议给我捡起来！ | 失控 | 3.5s | none |
| 10 | 林晚 | 顾言，这一次换你来求我。 | 轻描淡写 | 4.5s | none |
| 11 | 助理 | 林总，您落了一份很重要的文件。 | 恭敬 | 4.0s | none |
| 12 | 林晚 | 股权代持……原来他一直都知道。 | 怔住 | 4.5s | none |
| 13 | 助理 | 顾总交代过，不让我告诉您。 | 低头 | 3.5s | none |
| 14 | 林晚 | 那就让他，慢慢等着吧。 | 冷 | 4.0s | none |

> 核算：台词 186 字（去标点）÷ 4 字/秒 ≈ **47s 口播**；14 个对白镜共 72.8s，扣掉口播后留出 ≈26s 反应/停顿/走位；加 3 个动作镜 15.6s 与转场镜 3s ⇒ **≈91s ✅**
> 关键：**集长由镜头数×镜长决定**；台词字数只用来校验「这句话塞不进这个镜长」——单镜台词 ≤ 镜长×4 字/秒 − 0.2s。

## ④ 8 列镜头意图
| 镜号/时长 | 场 | 说话人&台词 | 表演意图 | 景别/运镜 | 空间位置 | 续接意图 | 节拍 |
|---|---|---|---|---|---|---|---|
```

## 7. 交给生产层之前的自检（10 项，全过再加载 story skill）

1. 六节齐全，没有空节。
2. 台词逐字来自剧本，**没有改写、没有概括**。
3. 每句台词都有说话人；一镜一说话人（同镜没有第二个说话人）。
4. 镜数 = 对白句数 + 动作镜 + 转场镜，且 ≈17–18。
5. 整集台词字数 ÷ 4 字/秒 ≤ 90s。
6. 场次数 ≤2；跨场景边界有且仅有 1 个转场镜，且它在两场之间。
7. 每镜都有景别与空间位置；相邻镜景别不重复。
8. ⑤ 的资产都写了 id 或 `TO-BUILD`；`TO-BUILD` 不超过 2 个。
9. ⑥ 十项齐全，与系列圣经一致（画幅/档位/字幕/语言/风格）。
10. 集尾有钩子，下一集开头 30s 内有回应（对齐分集目录）。

不满足 → 回改包，**不要**带着缺口进生产层（缺口会在镜头表自检门被放大成返工）。
