## 3. 结论（暂定）

1. **H3 会执行 `non_diegetic_music`**：有/无 BGM 的音频差异显著（约 20 dB + 调性差异）。
2. **BGM 是烘进该镜音轨的**：A1 的 BGM 与对白/音效在同一条 32kHz 2ch 轨里，不能单独导出/duck。
3. **链式续接不保证 BGM 原样延续**：B2 仍有音乐，但电平与接缝相关性不足以证明“同一段音乐无缝接上”；需要人听。
4. **跨镜/硬切 BGM 连续性**未验证；按当前机制，硬切/跨场景会各自生成，音乐可能换曲/断掉。

## 4. 对产品选项的含义

- `bgmMode=in-model` 可行，但要明确：**逐镜 BGM、不可单独替换/duck、链内可能衰减、硬切会断**。
- 适合：对白少、氛围向、能接受“每镜一段配乐”的短片/短剧。
- 不适合：需要一条贯穿全片、可后期调音量/替换的 BGM——那需要 `separate`（Music 3 + 后期混音）。
- 若用 `in-model`，H3 prompt 的 `non_diegetic_music` 要写**本镜**的乐器/速度/动态/进点；不能写“整场从第 3 分钟进 BGM”，H3 看不到全局。
- 若用 `separate`，H3 必须 `N/A`，否则双 BGM。
