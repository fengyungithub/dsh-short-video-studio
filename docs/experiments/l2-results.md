## 4. 发现（9 条）

### 已修（7 条）

| # | 发现 | 修在哪 |
|---|---|---|
| L2-1 | **「前 0.9s 还是上一镜」是采样期概念，交付已裁掉**：S02/S03 交付首帧就是新构图；按旧规则把对白推到 1.2s = 白让表演时间 | SSG 第 10 项重写（并保留旧写法作对照说明） |
| L2-2 | **声线门与 `canvas:` 冲突**：门写着「没有 `voice:<id>` 不许提交」，而表/包允许 `canvas:` | SSG 渲染前声线门：判据改为「有可解析音频引用（`voice:` 已入库 或 draft 下 `canvas:`）」 |
| L2-3 | **H3 段名必须带冒号**：`## subject_definitions` 会被判缺段并 deny | SSG STEP 7 补一行「段名行 = `段名:`」 |
| L2-4 | **转场 length 口径自相矛盾**：「建议 ≥56」vs「<124 属未测区」 | 统一为「走网格、建议 ≥73；低于 124 需样片集实测后固化」 |
| L2-5 | **「退场人物状态」语义**：反打里说话人不在画内，被误记成「仍在右中景」 | 明确「只记刻意离场；景别不在画内写 `—`」 |
| L2-6 | **三档同文容易只改一段**：分三次写，负向尾句只进了 quality | 明确「一次调用、同一字符串填三段」 |
| L2-7 | **时长回写仍只覆盖超时**（PROD §10 未同步 PACK） | PROD §10 改为双向（`\|Δ\| > T×10%`） |

### 待决策（2 条）

| # | 发现 | 说明 |
|---|---|---|
| L2-8 | **`voicePlan=existing` 在无 TTS 环境无解**：existing = 「库里有就复用、没就试镜补建」，但没有「没有 TTS 时怎么办」的口径 | 建议补「无 TTS → 降 `text-only` 或由用户提供 2–15s 干声；**不得用器乐占位冒充声线**」；本臂只能记风险 |
| L2-9 | **成本模型按 16:9 标定**：9:16 续接镜实测 217s vs 表里的 166s | 要么按画幅/续接比例给系数，要么在样片集重标 |
