# 单片 STEP 0 vs 剧集 STEP 0：参数对比

> 单片 = `story-short-generator` 的 `references/single-film-mode.md` §1（13 张规格卡 + 复用范围）
> 剧集 = `short-drama-series-production` 的 `S-STEP 0`（一张系列规格卡：3 套餐 + 4 组微调）＋ `story` 的 `E-STEP 0`（每集只读校验）
> 一句话：**单片是「一条片问 14–15 次」，剧集是「整季问 1 次 + 每集 0 次」，但代价是改任一项 = 换季。**

---

## 1. 全景对照

| # | 参数 | 单片 STEP 0 | 剧集 S-STEP 0（系列层，一次） | 剧集 E-STEP 0（每集） | 存哪 |
|---|---|---|---|---|---|
| 0 | **片型** | **门 0**：短视频故事 / 连续短剧 | 无（由路由/探测决定：有系列上下文直接进委托） | — | — |
| 1 | **复用范围** | **一张卡**（库非空时）：复用 / 全新 / 部分复用 | 无此卡 → 阶段 C 建资产 + **G-A 一次批准入库** | 只 `asset_to_canvas` 物化 | 资产库 |
| 2 | **集数** | 无（1 条） | **有**：50–100 | — | 圣经 §1 |
| 3 | **画幅** | 16:9 / **9:16** / 1:1 / **4:5** / 自定义（默认 16:9） | **9:16** / 16:9 / 1:1（默认 9:16） | 读回校验 | `state.aspectRatio` |
| 4 | **时长** | **整片** 30–180s（15–30 / 30–60 / 60–90 / 90–180） | **单集** 80–110s（默认 90s）＋ `episodeSecondsException` | 校验包 ① | `state.duration` |
| 5 | **音频模式** | dialogue-led / silent | 同 | 读回校验 | `state.audioMode` |
| 6 | **BGM 模式** | none / in-model（separate 下一期） | 同 | 校验 ⑥；in-model 要求镜头表逐镜 BGM | 圣经 + ⑥ |
| 7 | **声线方案** | audition（默认）/ existing / text-only，**有对白必答** | **existing（默认）** / audition / text-only | 校验 ⑥ + 台账 `voices[]` | 圣经 + ⑥ |
| 8 | **字幕** | **burned-in（默认）** / none | **none（默认）** / burned-in | 校验 ⑥（无 state 字段） | 圣经 + ⑥ |
| 9 | **视频档位** | fast / balanced / quality，可先 fast 后升档 | 同三档，但**整季同档**（档位闸）＋ 试产 `dryRun` 例外 | 读回校验 | `state.mode` |
| 10 | **角色卡版本** | single / **three（非 fast 推荐）**；fast → 只能 single | **single（默认）** / three；fast → 只能 single | 读回校验 | `state.characterCardVariant` |
| 11 | **图片档位** | balanced（默认）/ quality / fast（仅抽卡） | 同 | 校验 ⑥ | 圣经 + ⑥ |
| 12 | **交付画质** | 原生 / 后处理超分 / **生成内放大**（仅 16:9 且 ≤124 帧）/ **+48fps 可叠加** | native / upscale1080 / 2k / 4k / **fps48**（**整季二选一**） | 校验 ⑥ | 圣经 + ⑥ |
| 13 | **审查节奏** | **per-shot（默认）** / batch | **batch（默认）** / per-shot | 读回校验 | `state.reviewMode` |
| 14 | **逐镜自检门** | verdict（默认）/ frames / off | 同（量产建议恒 verdict） | 读回校验 | `state.shotGate` |
| 15 | **视觉风格** | 7 套，**pixar-3d 默认** | 7 套，**cinematic-live-action 默认** | 校验 | 圣经 + 简报 |
| 16 | **语言 / 出海** | 未单列（台词语言写进简报） | 中文 / English（出海） | 校验 | 圣经 |
| 17 | **每集场景数** | 无（全片场景自由） | **1–2 个物理场景** | 校验包 ② | 圣经 + 包 ② |
| 18 | **assetMode** | 无（用库就人工点入库） | **draft（EP01/试产）/ library（量产）** | 强校验：library 缺 asset id → 停线 | ⑥ + state |
| 19 | **分镜模式** | STEP 6 弹卡：text / text+pencil | **⑥ 预填**（text 默认） | 不弹卡 | ⑥ |
| 20 | **试产标记** | 无 | `dryRun: true`（fast 干跑） | 校验不得与交付集混拼 | state.series |

**结论：20 项里**

- **两边都有卡（14 项）**：画幅、时长、音频、BGM、声线、字幕、视频档位、角色卡版本、图片档位、交付画质、审查节奏、自检门、风格、分镜模式（单片是 STEP 6 独立卡 / 剧集是 ⑥ 预填）。
- **只有单片有（2 项）**：片型门 0、复用范围；另「生成内放大」是交付画质的子选项（16:9 且 ≤124 帧才可选）。
- **只有剧集有（4 项）**：集数、每集场景数、assetMode、dryRun（+ 单集例外的 `episodeSecondsException`）。
- **语言 / 出海**：剧集有独立选项；单片不单列（台词语言写进项目简报）。

## 2. 同样的参数、相反的默认（最容易踩的坑）

| 参数 | 单片默认 | 剧集默认 | 原因 |
|---|---|---|---|
| 视觉风格 | `pixar-3d` | `cinematic-live-action` | 合家欢短片 vs 国内竖屏短剧 |
| 画幅 | 16:9 | 9:16 | 平台形态 |
| 时长 | 30–180s 整片 | 80–110s/集 | 对白字数反推 |
| 字幕 | `burned-in` | `none` | 短剧靠投流字幕/无字更干净 |
| 声线方案 | `audition` | `existing` | 整季一次建、复用优先 |
| 审查节奏 | `per-shot` | `batch` | 单片返工便宜，整季人力贵 |
| 角色卡版本 | `three` 推荐（非 fast） | `single` | 9:16 下 three 未实测 |
| BGM | `none` | `none` | 一致 |
| 图片档位 | `balanced` | `balanced` | 一致 |
| 自检门 | `verdict` | `verdict` | 一致 |

> ⚠️ 从单片切到剧集（或反过来）时，凡「默认值」都会被另一侧的默认顶掉——**不要沿用上一侧的默认**，按当前模式的卡重新选。

## 3. 存储与回读：两边都不是「选完就完事」

| | 单片 | 剧集 |
|---|---|---|
| 有 state 字段（改即生效） | `aspectRatio` / `duration` / `audioMode` / `mode` / `characterCardVariant` / `reviewMode` / `shotGate` / `groupOrder` | 同 + `groupOrder` 用 **story 的十个标准组** |
| 无 state 字段（只能靠文本回读） | **交付画质 / 视觉风格 / 图片档位 / 字幕 / 声线方案 / BGM 模式（6 项）** → 写**项目简报** | 同 6 项 → 写**系列圣经 §1 + 集制作包 ⑥** |
| 每集重问？ | 不适用（一个会话到底） | **不问**；E-STEP 0 只读 + 校验，偏差才弹「规格偏差卡」 |
| 真值优先级 | STEP 0 卡 > 项目简报 | **系列圣经 §1 > production-state.series > 包 ⑥ > canvas state > 本集规格卡**（冲突停线，不许 AI 自选） |
| 改一项的代价 | 改简报 + 重写受影响镜 prompt / 重渲该片 | **换规格**：已产集作废或逐集重渲（改风格 = 全部卡片作废；改画幅/档位/字幕 = 已产集重渲） |

## 4. 决策频率与「少问」的代价

| | 单片 | 剧集 |
|---|---|---|
| 开片前人工卡 | **15 张**（门 0 + 复用范围 + 13 张规格；库空时 14） | **1 张**（3 套餐 + 微调） |
| 每集人工卡 | — | **0 张**（E-STEP 0 只读；偏差才弹） |
| 全片/整季校准点 | STEP 0 + 各阶段卡 | STEP 0 + **G-SAMPLE**（唯一整季档位/超分/three 的复核点） |
| 风险 | 前面问太多、后面返工便宜 | 前面问太少、**错一次错 80 集** |

**所以剧集的「少问」是靠三件事换来的**：① G-S 一次锁死规格；② G-SAMPLE 一次校准；③ E-STEP 0 的「不一致就停线」——三者缺一，少问就变成「静默将错就错」。

---

## 5. 实操建议

1. **先判断模式再谈参数**：有系列上下文（圣经/包/`series/` 目录）→ 剧集；一句话创意 → 单片。别在单片流程里问「集数」，也别在剧集里问「总时长 15–30s」。
2. **剧集开场先写 `canvas_set_state` 再建卡**：图片尺寸跟画布比例走（缺省 16:9 会让 9:16 项目的卡变横版，L1 实测踩过）。
3. **单片独有的「生成内放大」在剧集里不存在**（9:16 不支持），剧集要 1080 只能逐镜超分。
4. **剧集的每集「不问」不等于「不校验」**：`canvas_get_state` 读不到 / 与圣经不一致 → 停线找 production 重写，不许本 skill 默认补。
5. **改规格前先问一句代价**：单片改字幕 = 重渲该片；剧集改字幕 = 已产集全部重渲。这条差异比参数本身更重要。
